# 方太个性化膳食规划 Agent 部署文档

## 环境要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| Python | 3.10+ | 3.10 或 3.11 |
| CPU | 2 核 | 4 核及以上 |
| 内存 | 4GB | 8GB 及以上 |
| 存储 | 10GB | 20GB 及以上 |
| Docker | 可选 | 20.0+ |

系统默认使用 DeepSeek (`deepseek-v4-flash`)，需要配置 API Key。Embedding 默认使用 sentence-transformers 本地模型，无需外部 API。

## 本地启动

### 安装依赖

```bash
pip install -r requirements.txt
```

依赖包括 Flask、FAISS、sentence-transformers、requests 等。如果 `sentence-transformers` 安装较慢或环境不支持，系统会自动回退到确定性哈希方案。

### 配置环境变量

复制 `.env.example` 为 `.env` 并填写：

```bash
cp .env.example .env
```

编辑 `.env` 文件：

```bash
# DeepSeek 配置（必填）
DEEPSEEK_API_KEY=sk-your-api-key
DEEPSEEK_API_BASE=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-v4-flash

# Embedding 配置（可选，默认使用 sentence-transformers）
EMBEDDING_PROVIDER=sentence-transformers
EMBEDDING_MODEL=paraphrase-multilingual-MiniLM-L12-v2
VECTOR_DIMENSION=384
```

### 启动服务

```bash
python app.py
```

启动成功后访问：

```bash
curl http://localhost:5000/api/health
```

预期返回：

```json
{
  "status": "ok",
  "service": "方太个性化膳食规划Agent",
  "version": "1.0.0"
}
```

## Docker 部署

### 构建镜像

```bash
docker build -t fotile-agent .
```

### 运行容器

```bash
docker run -p 5000:5000 fotile-agent
```

带环境变量运行：

```bash
docker run -p 5000:5000 \
  -e DEEPSEEK_API_KEY=sk-your-api-key \
  -e DEEPSEEK_MODEL=deepseek-v4-flash \
  fotile-agent
```

## Docker Compose

```bash
docker-compose up -d
```

查看运行状态：

```bash
docker-compose ps
docker-compose logs -f
```

健康检查地址为：

```bash
http://localhost:5000/api/health
```

## 主要配置项

| 环境变量 | 说明 | 默认值 |
|----------|------|--------|
| `DEEPSEEK_API_KEY` | DeepSeek API Key | 空（必填） |
| `DEEPSEEK_API_BASE` | DeepSeek API 地址 | `https://api.deepseek.com/v1` |
| `DEEPSEEK_MODEL` | DeepSeek 模型名 | `deepseek-v4-flash` |
| `EMBEDDING_PROVIDER` | Embedding 方案 | `sentence-transformers` |
| `EMBEDDING_MODEL` | sentence-transformers 模型 | `paraphrase-multilingual-MiniLM-L12-v2` |
| `VECTOR_DIMENSION` | 向量维度 | `384` |
| `MAX_RETRIEVAL_RESULTS` | 单次最大检索结果数 | `10` |
| `TEMPERATURE` | LLM 生成温度 | `0.3` |
| `MAX_TOKENS` | 最大生成 Token 数 | `800` |

## 接口自测

```bash
# 健康检查
curl http://localhost:5000/api/health

# 用户档案

# 菜谱搜索
curl "http://localhost:5000/api/search?q=清淡&top_k=5"

curl -X POST http://localhost:5000/api/dialog \
  -H "Content-Type: application/json" \
  -d '{"user_id":"demo_user","message":"推荐一份清淡晚餐"}'
```

## 常见问题

### 依赖安装失败

`faiss-cpu` 对 Python 版本较敏感，建议使用 Python 3.10 或 3.11。如果安装失败，可先升级 pip：

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 服务启动失败

如果端口被占用，可更换端口或停止已有进程：

```bash
lsof -i :5000
kill -9 <PID>
```

### 远程 LLM 调用失败

先切换到本地模式验证基础功能：

```bash
export LLM_PROVIDER=local
python app.py
```

如果本地模式正常，再检查 API Key、网络连接和服务商模型配置。

## 安全建议

1. 不要把 API Key 写入代码仓库。
2. 生产环境应使用 HTTPS 和访问频率限制。
3. 用户健康档案属于敏感数据，正式部署前应增加脱敏和权限控制。
4. Docker 部署时建议使用独立密钥管理方式注入环境变量。
