# 方太个性化膳食规划 Agent 部署文档

## 环境要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| Python | 3.10+ | 3.10 或 3.11 |
| CPU | 2 核 | 4 核及以上 |
| 内存 | 4GB | 8GB 及以上 |
| 存储 | 10GB | 20GB 及以上 |
| Docker | 可选 | 20.0+ |

系统默认使用 `local` 模式，可在没有外部 API Key 的情况下完成基础检索、约束过滤和接口测试。若需要调用远程大模型，可通过环境变量切换通义千问、文心一言或 OpenAI。

## 本地启动

### 安装依赖

```bash
pip install -r requirements.txt
```

### 配置环境变量

默认本地模式：

```bash
export LLM_PROVIDER=local
```

使用通义千问：

```bash
export LLM_PROVIDER=qwen
export QWEN_API_KEY=your_api_key
```

使用文心一言：

```bash
export LLM_PROVIDER=ernie
export ERNIE_API_KEY=your_api_key
export ERNIE_SECRET_KEY=your_secret_key
```

使用 OpenAI：

```bash
export LLM_PROVIDER=openai
export OPENAI_API_KEY=your_api_key
```

### 启动服务

```bash
python app.py
```

启动成功后访问：

```bash
curl http://localhost:5000/api/health
```

预期返回：

```json
{
  "status": "ok",
  "service": "方太个性化膳食规划Agent",
  "version": "1.0.0"
}
```

## Docker 部署

### 构建镜像

```bash
docker build -t fotile-agent .
```

### 运行容器

```bash
docker run -p 5000:5000 fotile-agent
```

带环境变量运行：

```bash
docker run -p 5000:5000 \
  -e LLM_PROVIDER=qwen \
  -e QWEN_API_KEY=your_api_key \
  fotile-agent
```

## Docker Compose

```bash
docker-compose up -d
```

查看运行状态：

```bash
docker-compose ps
docker-compose logs -f
```

健康检查地址为：

```bash
http://localhost:5000/api/health
```

## 主要配置项

| 环境变量 | 说明 | 默认值 |
|----------|------|--------|
| `LLM_PROVIDER` | LLM 服务商，可选 `local`、`qwen`、`ernie`、`openai` | `local` |
| `QWEN_API_KEY` | 通义千问 API Key | 空 |
| `ERNIE_API_KEY` | 文心一言 API Key | 空 |
| `ERNIE_SECRET_KEY` | 文心一言 Secret Key | 空 |
| `OPENAI_API_KEY` | OpenAI API Key | 空 |
| `VECTOR_DIMENSION` | 向量维度 | `1024` |
| `MAX_RETRIEVAL_RESULTS` | 单次最大检索结果数 | `10` |
| `TEMPERATURE` | LLM 生成温度 | `0.3` |
| `MAX_TOKENS` | 最大生成 Token 数 | `2000` |

## 接口自测

```bash
# 健康检查
curl http://localhost:5000/api/health

# 用户档案
curl "http://localhost:5000/api/user/profile?user_id=3"

# 菜谱搜索
curl "http://localhost:5000/api/search?q=清淡&top_k=5"

# 膳食推荐
curl -X POST http://localhost:5000/api/recommend \
  -H "Content-Type: application/json" \
  -d '{"query":"今晚吃什么","user_id":"3","top_k":5}'

# 多轮对话
curl -X POST http://localhost:5000/api/dialog \
  -H "Content-Type: application/json" \
  -d '{"user_id":"demo_user","message":"推荐一份清淡晚餐"}'
```

## 常见问题

### 依赖安装失败

`faiss-cpu` 对 Python 版本较敏感，建议使用 Python 3.10 或 3.11。如果安装失败，可先升级 pip：

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 服务启动失败

如果端口被占用，可更换端口或停止已有进程：

```bash
lsof -i :5000
kill -9 <PID>
```

### 远程 LLM 调用失败

先切换到本地模式验证基础功能：

```bash
export LLM_PROVIDER=local
python app.py
```

如果本地模式正常，再检查 API Key、网络连接和服务商模型配置。

## 安全建议

1. 不要把 API Key 写入代码仓库。
2. 生产环境应使用 HTTPS 和访问频率限制。
3. 用户健康档案属于敏感数据，正式部署前应增加脱敏和权限控制。
4. Docker 部署时建议使用独立密钥管理方式注入环境变量。
